# Omni Platform

Omni is a modular, high-performance, type-safe, secure, accessible, observable, and scalable software platform.

---

## Architecture Overview

Omni strictly separates the **Control Plane** (authentication, business rules, database metadata) from the **Data Plane** (direct binary media transfers for images, GIFs, videos, and print assets).

```text
                                   OMNI PLATFORM
                                 
                 CONTROL PLANE                        DATA PLANE
     Agent / Console ─────────→ Server (Port 4000) ────────→ PostgreSQL
           │                         │
           │ (Direct Upload/Download)│ (Token Generation & Stats)
           ▼                         ▼
     Agent / Console ─────────────────────────→ Storage (Port 4001)
```

### Monorepo Workspaces (`workspaces/`)

- **[`server/`](file:///Users/muhammadimamrozali/RND/omni/server)**: Fastify 5 + Drizzle ORM + PostgreSQL + Zod + `@fastify/websocket` Control Plane backend (`port 4000`). Handles authentication, authorization, database persistence, and WebSocket gateway.
- **[`storage/`](file:///Users/muhammadimamrozali/RND/omni/storage)**: Dedicated Fastify 5 Data Plane service (`port 4001`). Handles direct media uploads (`POST /upload/:token`), controlled CDN media delivery (`GET /cdn/*`), atomic filesystem streaming, path traversal security, and disk space capacity monitoring (`B`, `KB`, `MB`, `GB`, `TB`).
- **[`console/`](file:///Users/muhammadimamrozali/RND/omni/console)**: Operator & Admin web dashboard built with React 19 + Vite + Tailwind CSS v4 + Zustand + REST API Client + GitHub Primer Dark UI.
- **[`agent/`](file:///Users/muhammadimamrozali/RND/omni/agent)**: Desktop client built with React 19 + Vite + Tailwind CSS v4 + Zustand + Tauri 2 + Rust native backend commands (`agent/src-tauri`).

## Quick Start & Development

```bash
# 1. Use Node 24 runtime
nvm use

# 2. Install monorepo workspace dependencies
npm install

# 3. Start development servers
npm run dev:server   # Starts Server Control Plane on http://localhost:4000
npm run dev:storage  # Starts Storage Data Plane on http://localhost:4001
npm run dev:console  # Starts Console Admin UI on http://localhost:3000
npm run dev:agent    # Starts Agent Desktop App on http://localhost:1420
```


## Security & Standards

- **Path Traversal Protection**: Storage service resolves canonical paths strictly within `STORAGE_ROOT` boundary (`resolveSafePath`).
- **Control Plane Token Signing**: Direct Data Plane uploads use HMAC SHA-256 signed session tokens generated by Server with a 15-minute time-to-live.
- **Strict Error Envelope**: All API endpoints return standardized JSON envelopes: `{ "success": true, "data": ... }` or `{ "success": false, "error": ... }`.
- **Theme & Aesthetics**: Frontend UIs adhere to GitHub Primer Dark design palette (`#0d1117`, `#161b22`, `#21262d`, `#30363d`).
